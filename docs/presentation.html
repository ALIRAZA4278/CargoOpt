The problem

Fractional Knapsack with Greedy

A truck (knapsack) can carry a limited weight W. Each package has a weight and a profit. Goal: get the maximum profit without going over W.

In Fractional Knapsack we may load part of a package (like half a sack of rice), so the last package can be loaded partly.

Greedy idea

At every step take the package that looks best right now, and never go back. Sorting + one pass = O(n log n).

Our project

What we built: CargoOpt

A web app that plans how to load a truck using the 3 Greedy strategies, written fully in Python.

  • Pick a lecture example or add your own packages
  • Truck drawing shows what is loaded (partly loaded = striped)
  • Step-by-step loading sequence for each strategy
  • Compare all 3 strategies, the best one is marked
  • Tick packages yourself and try to beat Greedy
  • Export the load plan as a CSV file

Real world

Where Fractional Knapsack is used

🚚 Cargo & trucks

Load bulk goods like rice, sugar or cement so a truck with limited capacity earns the most per trip.

⛽ Fuel & liquids

A tanker can carry part of any order, so the most valuable fuel per litre is loaded first.

💰 Investment budget

Split a fixed budget across options that can be bought in any amount, best return per rupee first.

☁️ Cloud & bandwidth

Share limited server time or network bandwidth between tasks, giving most to the highest value per unit.

Greedy works here because items can be divided.
For 0/1 Knapsack (no parts) Greedy may fail.
